# 繁體中文文字審查與修訂（2026-09-26）

依 speak-human-tw 1.4.0 審查，完成 68 項修訂，涉及 20 個原始檔；另重建 `dist/icd10.html` 與診間包。使用者已授權直接修改，本紀錄保留原句、原因及改後內容。

本紀錄為文字校對階段的驗證快照；同日後續 VAC 擴充、題數與最終封裝結果見 `2026-09-26-vac-expansion.md`。

## 範圍與保留項目

- 盤點 Git 追蹤的 139 個 UTF-8 文字檔，其中 135 個含中文；全庫搜尋套話、誇大、台灣用語及標點問題，逐一複核候選段落。主要修訂 README、診間說明、維護文件、介面提示與註解。
- 文類為軟體操作／維護文件。Sepia 用於檢查語域與資訊密度，speak-human-tw 用於句子與台灣繁體中文校對。必要列表、表格、技術對比與限制保留，不以命中詞彙就直接替換。
- 疫苗、藥物、ICD 代碼等 `src/curated/` 資料未改；原始來源、授權文件、使用者引文、歷史規劃與量測紀錄保留。自動產生的臨床內容驗收清單未直接改寫。
- 修正操作文件與目前實作的矛盾：已移除的相關推薦、貼齊熱鍵預設不置頂、包內來源資料夾、已存在的品項反查與抗菌藥劑量表。品項敘述依內建資料核對，不代表重新查核當期健保政策。
- 本次為文字與操作文件審查，未重新進行全套醫學內容查證。

## 驗證

- JavaScript 既有測試：203 項通過。
- Python 相關測試涵蓋建置、打包、慢病資料、品項、VAC、三版面選碼、Lipid 與 BSA：首輪 103 項通過、1 項建置寫入失敗。該項單獨重跑通過，再重跑整個 `tests/test_build.py`，12 項全部通過；此次涵蓋的 104 個不同測試均已通過。
- 首輪錯誤為寫入 `dist/icd10.html` 時出現 `OSError: [Errno 22] Invalid argument`，後續未重現；未確認成因，未因此修改建置邏輯。
- 實際介面：1440px 工作台、390px 手機、340px／176px 側掛，日夜各一次。dist 與診間包各完成 8 組操作；四段提示換行有效、無水平溢出，填入身高後顯示三種體重結果，VAC 27 題預設收合且可展開。
- 初次檢查發現 `.lipid-t2-caution` 與 `.lipid-lookup-more` 未保留換行，補入既有 `white-space: pre-line` 規則後通過。
- Python AST 比對確認執行邏輯不變；修改的 JS 通過語法檢查且與逐項變更清單一致。CSS 除兩個提示加入換行規則外，僅修改註解。
- 醫療資料與來源文字雜湊不變；26 份疫苗來源、4 份健保 PDF、HTML 與使用說明均核對包內內容一致。診間包 34 個檔案、21,346,707 bytes（約 20.36 MiB）；前版 ZIP 已備份至本機 `.review/speak-human-tw/`。
