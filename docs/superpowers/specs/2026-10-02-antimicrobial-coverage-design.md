# 抗微生物製劑健保給付速查設計草案

日期：2026-10-02
狀態：使用者已確認設計，已實作並於 2026-10-03 完成交付驗證。

## 目標與方案

在現有 ICD-10 門診導引加入「抗微生物給付」獨立面板，沿用 VAC 的離線搜尋與展開模式。相較於擴充慢病分頁，獨立面板更適合大量藥物的搜尋與分類；相較於連到外部網站，內嵌資料可在診間離線使用。採獨立面板方案，不新增後端。

## 查詢流程

工作台、側掛窄欄與手機皆提供入口，位置沿用既有工具列。開啟時關閉其他速查面板，保留診斷清單。支援學名、官方原文所列商品名、已核對縮寫、條號與條件關鍵字搜尋；可篩選抗細菌、抗黴菌、抗病毒及其他類別。縮寫由明確對照表處理，不猜測藥名。

搜尋結果先顯示藥名、條號與簡短給付重點，展開後列出適用感染／病原、先前治療或藥敏要求、年齡／劑型限制、療程／數量限制及審查／檢附文件要求。僅呈現原文存在的限制，各項一行，保留「且／或」與例外的階層。共通規定獨立提供入口，相關藥物連回適用通則。每筆可複製條件與來源。

## 資料範圍與來源

完整索引健保署第十節「抗微生物劑」的有效條文，包括通則與個別藥物；已刪除條文不當成現行給付條件。第十節未列專屬規定的藥物，不推論為不給付或無限制。肝炎等複雜條文保留各適應症分支，不壓成單一句話。

官方來源：https://www.nhi.gov.tw/ch/cp-7593-ad2a9-3397-1.html
本次確認清單標示第十節版本：115.07.23 更新。實作時下載清單實際連結文件，逐條核對內容及後續已生效修訂公告；不能單憑文件更新日推論所有條文的生效日。

保存官方原文與便讀摘要，逐筆記錄條號、來源文件、頁碼、文件版本、查證日期及原文明示的生效日。公告未生效版本另標示，不提前套用。摘要不推算個別病人的核付結果，不將管理計畫的登錄要求混同所有藥物的給付條件。

## 架構與整合

新增一份結構化給付資料、純搜尋／複製文字模組與面板呈現模組，使用專案既有 JavaScript 與 CSS 模式。建置驗證必填欄位、唯一識別碼、條號、日期及來源檔案存在，將資料內嵌至單一 HTML。官方文件存入「健保條文」並納入 dist、診間包及 GitHub Pages 發布檔案清單。資料錯誤讓建置失敗，搜尋無結果顯示清除條件及改搜提示。
