# 剪貼簿輸出設定設計草案

狀態：使用者已核准「預設格式＋可編輯範本」，已依此實作。

## 目標

在設定新增「剪貼簿輸出」頁，集中調整網站所有主動複製與自動複製的文字樣式。桌機、手機、側掛窄欄與置頂小視窗共用設定。保留本次工作區的既有 Lipid 修改與院內品項資料。

## 已盤點的輸出

1. 日期按鈕：主視窗與 PiP 各有入口，須統一格式化。
2. 診斷清單：加碼、移除與格式變更時自動同步剪貼簿，HIS 預覽共用同一結果。
3. 單一診斷碼：點擊清單代碼，以及鍵盤 Enter／Space。
4. Lipid：複製表一、表二、Fibrate 的判定與依據。
5. CCr：複製計算結果，目前包含 CCr、單位、體重依據與所用體重。

手動複製備援對話框沿用已套用格式的文字，不另設一套樣式。AutoHotkey 讀取剪貼簿而不產生這些輸出，不納入本次格式編輯器。

## 建議互動

設定 → 剪貼簿輸出 → 選擇輸出類別。

每類提供預設格式、可編輯文字範本、可插入欄位清單、即時預覽、儲存及還原該類預設。使用者能修改文字標籤、欄位順序、換行、標點、前後綴與要保留的欄位。動態數值與醫學判定以欄位插入，不直接改寫計算結果。

- 日期提供民國／西元及常見分隔方式。
- 診斷清單提供逐行、逗號分隔、含名稱，並允許自訂單筆格式與筆間分隔。
- 單碼提供代碼與名稱欄位。
- Lipid 提供個案資料、各表判定、分級、理由、門檻、目標與來源等欄位；每張表可依共同段落範本輸出。動態判定完整保留可直接用藥、先生活型態調整、不符合與待判定的區別。
- CCr 提供數值、單位、體重依據、所用體重，以及現有計算可取得的相關欄位；缺值不輸出 undefined／null。

使用明確標示的範例資料預覽，調整範本不直接寫入系統剪貼簿。儲存後套用到後續複製，並保留於目前瀏覽器；重新開啟仍可使用。首次使用與還原時維持現有預設輸出。

## 實作界線與驗證

共用格式化模組處理所有輸出，畫面預覽與實際複製呼叫相同程式；不執行使用者範本中的 JavaScript 或 HTML。儲存前驗證欄位名稱並顯示可修正的錯誤，不靜默略過。載入損壞設定時保留可用預設並提示。

先以測試涵蓋預設相容性、自訂格式、缺值、無效範本、設定保存與還原，再接上各個複製入口。實際驗證三種版面、置頂小視窗、HIS 預覽與剪貼簿一致，以及 Lipid 四種判定不被格式化錯誤改寫。最後重建 HTML 與診間包。

## 已確認的選擇

採用「預設格式＋可編輯範本」，包含清單單筆／分隔設定及 Lipid 各表段落範本。
