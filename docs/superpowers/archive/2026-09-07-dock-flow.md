# 側掛窄欄操作改善

使用者主要使用窄欄，痛點是找碼、切部位和加選需要反覆捲動或點擊。保留高密度、離線單檔、既有代碼與臨床內容。

## 設計與驗收

- 搜尋有結果時專注呈現結果，直接回到結果頂端；提供返回按鈕與 Escape，返回原部位的捲動位置。選部位／模式時結束搜尋。
- 每個模式與部位各記住本次開啟期間的捲動位置；第一次進入從頂端開始。展開疾病不重建其他面板、不丟失鍵盤焦點。
- 面板標題可整列點擊展開疾病，捲動時標題留在內容區頂端；字級不縮小。
- 已選碼在原位標記勾號與可讀說明，重複點擊仍保留既有喚回相關建議的行為。移除／清空後同步取消標記。
- 相關疾病預設高度縮減至 96px，提供收合按鈕及數量；清單預設上限 120px，保留手動拖曳調整及原有複製功能。
- 176／340／565px、日夜主題皆無水平溢出；真實 Document PiP 中新操作照常運作。

1. 在 `tests/test_e2e_dock_flow.py` 加入搜尋、部位記憶、展開焦點、選碼標記、下方高度與 PiP 操作回歸案例；先實跑確認失敗原因。
