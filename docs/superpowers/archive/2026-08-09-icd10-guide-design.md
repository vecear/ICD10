# ICD-10 門診導引頁面 — 設計文件

- 日期：2026-08-09
- 狀態：已核可（使用者於對話中核可，含兩項預設確認）
- 使用者：內科（感染科）醫師，門診看診時需輸入 ICD-10 診斷碼至 HIS

## 1. 目標

一個**單一 HTML 離線檔**，門診看診時快速找到並複製 ICD-10-CM 診斷碼：

1. **症狀導向**：點症狀展開「症狀碼＋常見鑑別診斷精選碼」。
2. **內科預設、可切外科**：切換影響症狀面板與快選區內容。
3. **慢性病／感染科常用快選**：固定內建清單（不做個人化）。
4. **相關代碼推薦**：每加入一個碼，跳出相關碼供連鎖加選（盡量多 key 診斷）。
5. **累積清單＋一鍵複製**：一個病人多個診斷一次帶進 HIS。
6. **全庫搜尋**：涵蓋健保現行 ICD-10-CM 2023 年版全部診斷碼（中文／英文／代碼前綴）。

## 2. 技術方案

- 純 vanilla JS，無框架。
- 全庫資料以 gzip 壓縮 + base64 內嵌於 HTML，載入時用瀏覽器原生 `DecompressionStream('gzip')` 解壓。
- 最終產出單一 `.html`（預估 3–4 MB），`file://` 雙擊即開、完全離線。
- Python 建置腳本：健保署 CSV → JSON → gzip → base64 → 與 HTML 模板合併輸出 `dist/`。
- 複製功能：`navigator.clipboard.writeText`（Chrome/Edge 在 file:// 為 secure context）＋ `document.execCommand('copy')` 隱藏 textarea 後備方案。

### 資料來源

- 全庫：政府資料開放平臺「2023年版_中文版ICD-10-CM/PCS(正式版)」<https://data.gov.tw/dataset/177507>（健保署發布，CSV）。**只取 CM 診斷碼（約 7.4 萬筆），不取 PCS 處置碼**（門診用不到）。
- 每筆欄位：代碼、英文名稱、中文名稱、是否為最細階（葉碼）——實際欄位以下載後確認為準。
- 精選資料（症狀面板、快選、關聯表）：人工整理，內嵌為獨立 JS 資料檔，建置時驗證每一碼皆存在於全庫且為可申報葉碼。

## 3. 介面佈局（單頁）

```
┌─────────────────────────────────────────────┬──────────────┐
│  🔍 全庫搜尋（中文/英文/代碼皆可）  [內科|外科] │  本次就診清單  │
├─────────────────────────────────────────────┤  ・E11.9 DM  │
│  ▼ 症狀導向面板                               │  ・I10 HTN   │
│  發燒 咳嗽 喉嚨痛 腹痛 腹瀉 頭暈 胸痛 排尿不適…  │  ・N39.0 UTI │
│  （點症狀 → 展開症狀碼＋常見鑑別診斷精選碼）      │              │
├─────────────────────────────────────────────┤ [一鍵複製]    │
│  ▼ 常用快選                                  │ [清空]        │
│  【慢性病】HTN、DM、高血脂、CKD、痛風…          │  ▼ 相關代碼   │
│  【感染科】UTI、肺炎、蜂窩性組織炎、帶狀疱疹…    │  （點碼後跳出）│
└─────────────────────────────────────────────┴──────────────┘
```

### 互動規格

- **搜尋**：即時（debounce ~150ms），比對代碼前綴、英文子字串、中文子字串；顯示前 50 筆；非葉碼標示「不可申報」或直接過濾（實作時依全庫欄位決定，預設：顯示但標灰、不可加入清單）。
- **內科/外科切換**：預設內科。只影響症狀面板與快選區；搜尋、就診清單、相關碼推薦不受影響。
- **加入清單**：點擊任何碼（搜尋結果、面板、快選、相關碼）即加入右欄清單；重複點擊不重複加入；清單項可單獨移除。
- **就診清單生命週期**：重新整理即清空（每個病人一輪）——使用者已確認。
- **一鍵複製**：三種格式——純碼換行（預設，使用者已確認）／純碼逗號分隔／碼＋中文名稱。另支援清單內單碼點擊複製。
- **相關代碼推薦**：每次加入一個碼，右欄下方顯示兩層相關碼：
  1. **人工關聯表**（約 50 組）：臨床邏輯關聯，如 E11.9 → E78.5、I10、E11.22、E11.40…；N39.0 → N10、B96.20 等 B95–B97 病原體附加碼、Z16.12 ESBL。
  2. **同家族碼自動展開**：全庫中同類目（前三碼相同）的鄰近葉碼，零維護。
  - 點相關碼一樣加入清單並觸發新一輪推薦（連鎖）。

## 4. 精選內容規模

| 區塊 | 規模 | 備註 |
|---|---|---|
| 內科症狀面板 | 約 30 症狀 × 各 5–15 碼 | 發燒、咳嗽、腹痛、腹瀉、頭暈、胸痛、排尿不適… |
| 慢性病快選 | 約 30 個 | HTN、DM、高血脂、CKD 分期、COPD、AF、慢性 B/C 肝、甲狀腺… |
| 感染科常用 | 約 40 個 | UTI、肺炎、SSTI、帶狀疱疹、C. diff、TB、登革熱、恙蟲病…＋B95–B97 病原附加碼面板 |
| 外科模式 | 約 40 個 | 撕裂傷（S 碼常用完整七碼）、膿瘍、疝氣、痔瘡、甲溝炎、術後追蹤… |
| 關聯表 | 約 50 組 | 含慢病組合與感染科組合 |

所有精選碼必須是健保可申報的最細階碼（建置時機器驗證）。

## 6. 錯誤處理

- `DecompressionStream` 不支援（舊瀏覽器）→ 顯示明確訊息「請使用 Edge/Chrome 80+」而非白畫面。
- 剪貼簿 API 失敗 → 自動退回 execCommand；再失敗 → 彈出可手動全選複製的文字框。
- 搜尋無結果 → 顯示「查無結果，試試英文或代碼前綴」。

## 7. 測試

- **資料完整性（Python）**：全庫筆數核對（與 CSV 原始筆數一致）、無 `�` 亂碼、中文欄位無簡體字（用明確簡體專用字集）、精選碼 100% 存在於全庫且為葉碼、關聯表雙向無 dangling code。
- **Playwright E2E**（開 dist 單檔）：搜尋中/英/代碼三途徑、內外科切換、症狀面板展開、快選加入、相關碼跳出與連鎖加入、複製三種格式內容正確、清單移除與清空、重新整理清空。
- **效能**：開檔到可互動 < 2 秒（本機 file://）。
