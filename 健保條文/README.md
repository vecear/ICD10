# 健保條文（官方 PDF）

慢病速查每個主題最上方的「官方條文」連結指到這裡的檔案。診間電腦不能上網，
所以條文必須跟 `icd10.html` 一起寄過去、放在同一層的 `健保條文/` 資料夾裡。

`src/curated/chronic_care.json` 的 `docs[].file` 只寫檔名。檔名對不上這裡的實際檔案，
`python build/build.py` 就會失敗，避免診間點開連結時才發現缺檔。

## 各主題連哪幾份

| 主題 | 文件 | 相關條號 |
|---|---|---|
| DM | 第五節 | 5.1 糖尿病用藥 |
| DM | 第二節 | 2.14 sacubitril+valsartan、2.16 SGLT2 心腎適應症 |
| HTN | 第二節 | 2.7 metoprolol succinate、2.9 利尿劑等個別品項 |
| LIPID | 第二節 | 2.6 降血脂藥物（2.6.1 表一／表二、2.6.3、2.6.4 PCSK9） |
| LIPID | 附表二-D | 2.6.4 PCSK9 事前審查用表 |
| 三者皆有 | 通則 | 通則三、四、七、九 |

**HTN 為什麼連的是第二節而不是「降血壓藥給付規定」**：藥品給付規定裡沒有這種東西。
降壓藥的給付邊界是仿單適應症（通則七），第二節裡只有 2.7、2.9 這些個別品項有條文，
而且限制的都是「拿來治高血壓以外的用途」。這件事在 HTN 那一頁的條目裡也講了。

## 更新

「抗微生物給付」引用第十節，資料位於 `src/curated/antimicrobial_coverage.json`。
涵蓋 60 條有效規定，包含通則、劑型、抗細菌／抗黴菌／抗病毒（含 HBV／HCV／HIV）。
資料記錄官方 PDF SHA-256 與條文起始頁；建置、診間包及 Pages 皆須附上文件。
`build/import_antimicrobial.py` 可由已存 PDF 重建原文及頁碼，條號異動時會中止並要求人工核對。
新增／修訂摘要、別名及有效期間仍須逐條核對，不由腳本猜測。
第十節未列專屬條文不代表不給付；健保品項收載狀態及通則附表一仍須另查官方資料。
HBV DNA 與 FIB-4 公式上標在 PDF 純文字擷取後會展平，呈現及複製由已核對的對照恢復上標；原始文字保留供比對。

健保署改版時（藥品給付規定約一年改幾次）：

1. 到清單頁下載新的 PDF，檔名照 `藥品給付規定-第N節-名稱-版本日.pdf` 的格式。
2. 刪掉舊檔，更新 `src/curated/chronic_care.json` 裡對應的 `docs[].file` 與 `version`。
3. 上面那張表的下載網址與下載日一起更新（網址每次改版都會換）。
4. `python build/build.py && python tools/pack_for_clinic.py`，重新寄一次診間包。

條文換版時，須逐條核對 `chronic_care.json` 的摘要，再更新 `checked` 日期，
避免 PDF 已換版、摘要仍沿用舊內容。
